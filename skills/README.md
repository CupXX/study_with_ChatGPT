# Skills

This directory is for reusable skills created, adapted, or validated for this workspace and future projects.

Do not edit vendored third-party skills in place. If a third-party skill needs customization, create a local derivative here and document its source and differences.

## Available skills

- [`chatgpt-to-codex-handoff`](./chatgpt-to-codex-handoff/SKILL.md) — Use when a ChatGPT conversation needs to hand context, decisions, and next actions to Codex without duplicating repository sources of truth.
