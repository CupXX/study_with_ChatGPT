Program / Process / Runtime

快速判断：你现在说的是“文件里的东西”、“正在运行的实例”，还是“负责执行它的环境”？

四个最容易混的词

Source code（源代码）：人写下来的程序描述。它是静态内容，本身不会主动做任何事情。

Program（程序）：为完成某个任务而组织起来的指令/软件制品。日常语境里它可能指源码，也可能指已经能执行的软件；所以真正讨论运行机制时，要继续问“它现在运行了吗？”

Process（进程）：操作系统中一个正在运行的程序实例。它有自己的 PID、内存空间、环境变量和其他运行资源。

Runtime（运行时/运行环境）：让某种程序真正能够执行的那套环境。以 JavaScript 为例，Node.js 是一个 JavaScript runtime environment；它包含执行 JavaScript 所需的引擎，并提供文件、网络等宿主能力。

最重要的一句话：代码可以一直躺在磁盘里；只有当某个运行环境把它启动起来，操作系统才会出现一个真正活着的进程。

Node.js 例子

项目文件没有因为你安装 Node 22 或 Node 24 而自动改变；改变的是“哪一版 Node runtime 来执行这些文件”。当你在终端启动一个 Node 应用时，系统会创建一个 Node process。终端关闭、进程被终止，那个正在运行的实例也就没有了；代码文件仍然在。
