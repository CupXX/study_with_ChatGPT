# Learning

This directory stores course missions, curricula, lesson records, exercises, and progress.

Course design begins from an explicit learning mission. A teaching skill defines **how** to teach; each course mission defines **what capability** the learner is trying to gain.

## Planned starting tracks

- Software Fundamentals
- MBTI
- AI Agents & Harness Engineering

Course missions and syllabi will be created only after the learning goals are discussed and agreed.
